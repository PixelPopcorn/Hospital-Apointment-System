# Hospital Appointment System

A simple front-end website for **City Care Hospital** where visitors can view doctors, browse departments, search for doctors, and submit an appointment request.

> This is a student front-end demonstration only. Do not enter real patient information.

## Features

- Navigation menu and hospital home page
- 6 departments: Cardiology, Neurology, Pediatrics, Orthopedics, Dermatology, Ophthalmology
- 8 doctors, each with name, specialization, department, available day and available time
- Doctor search
- Appointment request form (patient name, email, phone, department, doctor, date, time)

## Technologies

HTML, CSS, JavaScript, Git and GitHub, GitHub Pages
